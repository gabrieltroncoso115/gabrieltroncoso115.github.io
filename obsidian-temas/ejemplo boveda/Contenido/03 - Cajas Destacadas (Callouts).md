# 📦 Cajas Destacadas

Los Callouts nativos usan variables semánticas específicas para el color de fondo, iconos y bordes laterales.

> [!note] Nota (Por defecto)
> Este es el callout estándar. Revisa el contraste general.

> [!tip] Consejo (Positivo)
> Ideal para probar colores de acento positivo (verde/turquesa).

> [!warning] Advertencia
> Prueba aquí tus colores cálidos, amarillos o naranjas de alerta.

> [!danger] Peligro / Error
> Crítico para revisar los tonos rojos semánticos.

> Esta es una cita en bloque tradicional (Blockquote). Úsala para calibrar el deslizador del grosor del borde lateral y el color de texto.
