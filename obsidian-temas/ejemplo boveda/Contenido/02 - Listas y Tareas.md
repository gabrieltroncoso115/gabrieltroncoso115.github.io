# 📌 Listas y Tareas

A continuación evaluamos el espaciado de viñetas, guías de indentación y cajas de tareas.

**Lista de viñetas:**
* Primer elemento de la lista.
* Segundo elemento para medir la separación vertical.
* Tercer elemento con **negritas** aplicadas.

**Lista numerada:**
1. Primer paso de la configuración.
2. Segundo paso operativo.
3. Tercer paso final.

**Lista de Tareas (Checkboxes):**
- [ ] Tarea pendiente estándar.
- [x] Tarea completada (evalúa el color de texto atenuado/tachado).
- [/] Tarea en progreso.
- [-] Tarea cancelada.
